## Architecture
- **Frontend**: React 19 with Tailwind CSS, RadixUI components
- **Backend**: FastAPI with MongoDB (motor async driver)
- **Database**: MongoDB with collections for customers, users, coupons, feedback, etc.

## What's Been Implemented (March 6, 2025)
- Cloned and set up the GitHub repository
- Installed all frontend (yarn) and backend (pip) dependencies

- Backend running on port 8001 with FastAPI
- Frontend running on port 3000 with React

## Core Features
- **Authentication**: Unified login for customers (OTP) and restaurant admins (password)
- **Customer Portal**: Profile, orders, points, wallet, coupons
- **Restaurant Config**: App configuration, branding, banners, custom pages
- **Feedback System**: Customer feedback submission and management

## User Personas
1. **Customers**: Restaurant patrons who can view menus, track points/wallet, view orders
2. **Restaurant Admins**: Configure app appearance, manage banners, view feedback
